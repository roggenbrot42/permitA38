# Getting help

* **Using permitA38:** start with the [README](README.md), [Getting started](docs/getting-started.md) and
  [Docker guide](docs/docker.md).
* **Bugs and feature requests:** open an [issue](https://github.com/roggenbrot42/permitA38/issues/new/choose) using the
  forms. For pre-releases use the *Alpha feedback* form.
* **Security problems:** do not open a public issue. Use *Report a vulnerability* in the Security tab (see
  [SECURITY.md](SECURITY.md)).
* **Tax questions:** permitA38 gives estimates, not tax advice. Ask your tax advisor (Steuerberater).

This is a volunteer project; there is no support-level agreement.
